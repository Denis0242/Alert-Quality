# Project Scope

## Purpose
Evaluate the quality and operational performance of AML transaction-monitoring alerts and rules at an analyst / analytics level.

## Questions answered
- Which rules generate the most alerts?
- Which rules have the highest false-positive rates?
- Which rules produce stronger escalation and SAR conversion?
- Where are QA failures concentrated?
- Which rules create aging or workload pressure?
- Which rules should be prioritized for threshold / logic review?

## In scope
- Alert volume analysis
- False-positive analysis
- Escalation rate
- SAR conversion
- QA pass/fail analysis
- QA issue categories
- Alert aging
- Analyst review productivity
- Rule review prioritization
- Tableau and Streamlit reporting

## Out of scope
- Production rule deployment
- Automated threshold changes
- ML model tuning
- Independent model validation
- Regulatory model-risk governance

All data is synthetic.
