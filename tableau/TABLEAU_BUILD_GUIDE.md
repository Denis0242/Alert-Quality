# Tableau Build Guide

## Project 6 — Approved Final Dashboard

### Design
- White background
- Thin light-gray borders
- Use only BLUE and ORANGE for analytical visualizations
- Navy/dark blue may be used for headings and text
- Dates use MM/YY, e.g. 07/26
- Six KPI cards
- Exactly six analytical visualizations
- QA Results by Analyst uses a stacked bar chart

### KPI Cards
1. Total Alerts
2. False Positives
3. Escalated Alerts
4. SAR Filed
5. QA Reviews
6. Avg. Review Time

### Six Visualizations
1. Alerts, Escalations & SAR Trend — combined trend lines
2. Alert Disposition — donut
3. Top 5 Rules by Alert Volume — bar chart
4. Alert Activity Heatmap (Day vs Hour) — values inside cells
5. Review Time vs Alert Risk Score — scatter plot
6. QA Results by Analyst — stacked Pass vs Fail bars

### Color logic
- Blue: baseline / total / pass / closed activity
- Orange: exceptions / escalation / fail / higher-risk activity

The packaged `images/02_executive_dashboard.png` is the approved visual reference.
